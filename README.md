### 🚀 About the Project
JobMatch AI was designed to simplify the candidate onboarding and resume-scanning process. The interface focuses on a clean dashboard, seamless navigation, and clear data visualization for match scores.

### ✨ Key Features
* **Candidate & Recruiter Dashboards:** Tailored views for tracking applications and AI insights.
* **Resume Optimization Flow:** Clean step-by-step UI for uploading and analyzing resumes.
* **Design System:** Built with reusable components, consistent typography, and a modern color palette.
